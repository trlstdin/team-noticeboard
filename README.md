## 操作
- 有编辑权限时，左上角切换编辑/只读。整张事项卡可以抓起拖动，同栏排序、跨栏移动，边缘自动滚动。手柄只是提示，不是唯一入口。
- 整个第一页只有一组五栏，五栏同时可见、禁止横向滚动；项目在栏内分组并整体折叠；已验收另可折叠。新项目、事项默认在前，可拖动项目顺序。
- 栏顶说明可直接输入保存。提出者、完成者与仓库地址在事项上展示。
- 主管在同页管理用户、公有账号及其授权。账号整行可拖给用户；Shift 连选、复选、全选、批量授权、清空授权、批量删除分别提供。
- 新签发的特殊链接默认仅复制。编辑与主管链接必须显式授予。删除用户、撤销链接后，旧 Cookie 和旧链接不能继续访问受保护操作。

## 身份与存储
本站 Cookie 保存短期不透明会话标识，服务端检查其来源、权限、过期和撤销；不把客户端填写的用户名或角色当作身份凭据。用户记录关联真实 GitHub 用户资料。GitHub OAuth/设备登录步骤不属于当前用户流程。

前端托管在 GitHub Pages；共享服务负责权限与加密账号 URL。GitHub Actions 每五分钟将告示快照和独立历史事件写入 `public-state.json` 与 `board-data/events/`。界面明确显示待入库和已提交版本；异步等待不冒充提交成功。事件文件不覆盖、不删除。完整历史可分页查看并全部导出。

公开快照不含账号凭据、用户授权表、Token 或加密私密历史。后台暂不可用时，页面显示快照状态，不假装保存成功。
