# 永久主管链接

按站点所有者明确要求签发独立主管访问链接。凭据为独立生成的 256 位随机值，源码仅保存 SHA-256 摘要；真实链接不入库、不放进测试、页面配置或公开日志。

原链接不设到期时间，不依赖 GitHub 访问令牌或登录会话。使用现有 `#session=` 入口换取 HttpOnly 浏览器会话，浏览器会话仍按现有 14 天期限管理；原永久链接可再次使用。主管链接身份单独标为 `permanent-supervisor`，不冒充 GitHub 登录身份。

保留既有登录和短期链接机制。匿名访问和错误链接不会获得额外权限。更换代码中的固定摘要会立即使原链接及其所有派生会话失效；私密存储中的 `capabilities/permanent-supervisor/<摘要>` 记录有 `revokedAt` 时同样拒绝原链接及派生会话。普通浏览器退出只结束该浏览器会话。

验证覆盖原生及实际解释执行后端：独立链接、长期时间推进、Cookie 恢复、主管写权限、派生会话、浏览器退出、撤销和匿名隔离。没有修改 DATA_KEY、托管绑定、环境变量或现有业务数据。
