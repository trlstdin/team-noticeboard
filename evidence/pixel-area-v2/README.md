# 当前版本：按完整树状图核算截图像素面积

来源：https://trlstdin.github.io/team-noticeboard/?area=3947abe 。截图为已发布公网页面，浏览器100%缩放，设备像素比1。保留原有深蓝色调和小标题，没有新增示例数据。当前看板没有事项，所以此结果说明空状态布局面积符合；不冒称有数据、展开对话框或其他页面均已测量。

## 统计口径

- 以实际UI分区的面积（含内部留白）计算，不按字号、字数或文字墨迹像素计算。
- 原始截图为 `1600x1000.png` 等；同名 `-mask.png` 是同一页面的临时纯色诊断截图，仅覆盖前景及背景显示，未更改布局和尺寸。
- Pillow逐像素读取PNG的RGB值，按唯一颜色计数，并以对应父区域的真实像素数计算子占比；不是读取CSS百分比后冒充实测。
- 全部像素均被归类，未分类像素为0。`-input.json` 保存颜色映射和当时的几何记录；`count-pixels.py` 可独立复算。

## 结果

1600×1000：七区域全部精确符合80%、7%、5%、4%、2%、1.5%、0.5%；所有子区域同样精确符合。事项区内部为标题8%、正文72%、仓库8%、人员时间10%、装饰2%。

1920×1080：第一层最大误差0.037037个百分点，子区域最大边界取整误差0.6个像素。

390×844：第一层最大误差0.028436个百分点，子区域最大边界取整误差0.597112个像素。

非整除尺寸保留真实数值，不伪写为完全相等。判定为第一层误差不超过0.1个百分点，子区域误差不超过1个物理像素的边界取整；这两种尺寸均通过。三种尺寸均无横向溢出、无JavaScript异常。

完整实际值、像素数量和误差见 `report.json`。
