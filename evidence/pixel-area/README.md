# 公网截图像素面积核算

截图来源：https://trlstdin.github.io/team-noticeboard/?pixel-layout=7dfdc3e 。浏览器缩放100%，设备像素比1。

- `1600x1000.png`、`1920x1080.png`、`390x844.png` 为公网实际页面截图。看板目前为空，没有添加示例或模拟真实内容。
- 对应 `-mask.png` 是对同一页面的真实分区临时覆盖唯一纯色后的诊断截图。只覆盖前景显示，不改变节点几何位置、尺寸或布局。
- 使用 Pillow 对诊断PNG逐像素读取RGB，按每种颜色的实际像素数量聚合。所有截图像素均被归类，无重叠、无未分类像素；未把CSS里的百分比作为实测结果。
- 统计口径为UI分区面积，包含其留白。不是字符字数，不是文字着色像素面积，也不再是字号占比。
- 子区域占比以各自父区域的实际像素总数为分母。
- 1600×1000 下，七个区域及全部子区域的实测比例与目标完全一致。
- 1920×1080、390×844 存在不可避免的整数像素取整；所有子区域边界偏差均不足1个物理像素，报告保留真实比例，不将它们伪写为精确目标值。
- 第一层误差限制为0.1个百分点；子区域以1像素边界取整为限制。`report.json` 给出实际值、像素总数、百分比误差和边界取整值。
- 三个尺寸均无横向溢出，无JavaScript异常。
