# 独立盘投屏 → 公有账号

一个当前投屏 URL 对应一个账号，使用现有账号池、加密和授权；环境关闭后撤下对应账号。独立盘已有主管会话用于同步，不新增服务端密钥或主机。链接和会话只保存在独立盘私密状态及服务端加密存储，不提交仓库。

`noticeboard-sync.cjs` 是独立盘发布器源文件，安装于已有 `public-cast/` 模块同目录，复用其 `runtime/` 依赖。独立盘配置在 `state/public-cast/noticeboard-publisher.json`，权限 600；首次启用仅需 `{"enabled":true}`，授权从本独立盘已有告示栏会话读取。该配置含运行凭据，不得公开或提交。

投屏后台仅需实例化发布器，并在现有完整环境扫描后调用 `observe(rows)`。`start(row)` 接原有、按环境排队的启动操作，`link(row)` 只返回本管理器所属运行实例的链接；后台退出时等待发布器 `close()`。环境首次打开自动启动投屏；原实例内手动关闭投屏的指令不会被周期轮询覆盖。

服务端 `/api/cast/sync` 每次使用原主管身份鉴权，URL 去重、加密保存。正常关闭主动撤下；来源意外失联时，30 秒在线期限到期后不再显示或允许复制。心跳单独保存在原 R2，不追加每次心跳事件、不竞争告示内容的版本写入。账号页和权限页每 2 秒更新一次，原告示板刷新节奏不变。

发布沿用仓库 main → GitHub Actions → 原 Sites 加载器，无需 Sites 权限。源变更在 worker/index.js 和 web/app.js；不要手改生成页面或 backend-release.json。
